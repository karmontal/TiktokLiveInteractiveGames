# معركة الساحة (3D)

مشروع Godot مستقل (Compatibility renderer، 720×720 مربّع، 30fps)، بيستقبل الأحداث من نفس LiveBridge.
الشاشة مربّعة عشان تنحط بالنص الفوقاني من بث TikTok، وتعليقات اللايف تضل تحتها وما تغطّي اللعبة.
التعليمات (لايك، فولو، شير، الهدايا) فوق تحت العنوان.

```
arena/
├─ ArenaGame.gd          # الشاشة: العالم 3D، المقاتلين، الكاميرا، الواجهة
├─ logic/ArenaLogic.gd   # القواعد (بدون شاشة، عليها اختبارات)
├─ logic/ArenaCamera.gd  # شو بتصوّر الكاميرا
├─ core/                 # نسخة من game/core: EventBus, AvatarCache, Music, Ui
├─ assets/characters/fighter.glb       # المقاتل (Blender)
├─ assets/environments/<theme>.glb     # البيئات (Blender، اختيارية) — المواصفات بـ README هناك
├─ assets/sky/<theme>.jpg              # سما كل بيئة (بانوراما)
├─ assets/textures/floor_<theme>.jpg   # أرضية الساحة لكل بيئة
└─ tests/run_tests.gd
```

**التشغيل:** `./run-live.sh اسم_حسابك arena` أو `./run-live.sh mock arena`.
من المحرر: افتح `arena/project.godot` واضغط ▶، وأزرار الكيبورد 1–9 و0 و- بتبعت أحداث وهمية (متل باقي الألعاب).

## القواعد

- **مقاتلين صاحب البث:** كل جولة بتبلّش بـ 3 مقاتلين باسم صاحب البث (مثلاً `karmontal 1` و`2` و`3`)، عشان الساحة ما تكون فاضية.
  بيقاتلوا لحالهم وممكن يفوزوا بالجولة، بس ما بيدخلوا لوحة الأبطال. ضربتهم نص القوة وبيطيروا أبعد لما مشاهد يضربهم،
  وما بتزيد قوتهم أبداً، فأي مشاهد بيقدر يغلبهم بسهولة. الاسم بيجي من `./run-live.sh اسم_حسابك arena`.
- **الانتظار (30 ثانية):** أول كل جولة في عدّاد دخول. أي تعليق (مش لازم كلمة join)، أو 5 لايكات، أو فولو أو شير أو هدية،
  بينزّل مقاتلك من السما (لحد 40 مقاتل).
  القتال ما بيبلّش قبل ما يكون في لاعبين اثنين على الأقل. اللي بيدخل بعد ما يبلّش القتال بينزل عادي، واللي بيوقع بيستنى الجولة الجاية.
- **القتال:** المقاتلين بيمشوا لأقرب خصم وبيلكموه لحالهم.
  - كل لكمة بتزيد ضرر الخصم (الرقم % تحت اسمه)، وكل ما زاد الضرر بيطير أبعد. الضرر بيرجع صفر بالهدية الصغيرة.
  - اللي بيطلع برا الحافة **خارج**، والإقصاء بينحسب لآخر واحد ضربه (خلال 4 ثواني).
- **الساحة بتصغر:** الجولة 5 دقايق. كل دقيقة الحلقة الخارجية بتحمر 10 ثواني وبعدين بتوقع:
  نص القطر 9 ← 7.5 ← 6 ← 4.5 ← 3.
- **الفوز:** لما يبقى لاعب واحد بالساحة بيبلّش عدّاد 30 ثانية. إذا ضل لحاله لآخر العدّاد بيفوز،
  وإذا نزل حدا جديد العدّاد بيتلغى والقتال بيكمّل. إذا خلص وقت الجولة، بيفوز الصامد صاحب أكثر إقصاء.
- **البيئة:** كل جولة بيئة عشوائية من الأربعة: جزيرة الغروب، البركان، الجليد، سطح المدينة.

| التفاعل | الأثر |
|---|---|
| لايك | ضربتك أقوى: +5% لكل لايك لحد +150% (30 لايك)، وبتخف شوي شوي (الشحنة الكاملة بتطوّل قريب دقيقة). البدلة بتضوي وفوق الراس بيطلع "قوة +X%" |
| فولو | درع بيصد أول ضربة |
| شير | اندفاعة: بيركض لأقرب خصم وبيدفش اللي بطريقه |
| هدية صغيرة | قلب: الضرر بيرجع صفر |
| هدية متوسطة | مطرقة 15 ثانية: الضربة ضعفين |
| هدية كبيرة | عملاق 10 ثواني: أكبر بـ 2.4، ضربته ×2.2، ما بيتحرّك كثير لما ينضرب، وموجة بتطيّر اللي حواليه |

**الكاميرا،** بالترتيب:
1. انهيار الحافة.
2. العملاق.
3. الإقصاء.
4. اللاعبين الجداد: لقطة وحدة كل 8 ثواني.
5. غير هيك أقرب معركة، ونصها للمتصدّر، وأحياناً لقطة عريضة بتدور.

كل الأرقام بأول `logic/ArenaLogic.gd`.

## الاختبارات

```bash
godot --headless --path arena --import
godot --headless --path arena -s res://tests/run_tests.gd
```
