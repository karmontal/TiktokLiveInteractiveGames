# ألعاب Godot

مشروع Godot 4.5 (Compatibility renderer، 720×1280، 30fps). بيستقبل الأحداث من LiveBridge (`../bridge`) عبر WebSocket.

```
game/
├─ core/EventBus.gd       # WebSocket ← LiveBridge، وبيطلق إشارة event_received
├─ core/AvatarCache.gd    # تنزيل صور البروفايل وتخزينها ودوائر 64×64
├─ core/Ui.gd             # أدوات رسم مشتركة (خطوط، ألوان، كروت، صور بروفايل)
├─ games/tug_of_war/      # شدّ الحبل: TugLogic.gd (القواعد) + TugOfWar.gd (الرسم)
├─ games/quiz/            # تحدّي المعلومات: QuizLogic.gd + QuizGame.gd + packs/*.json (بنوك الأسئلة)
├─ tests/run_tests.gd     # اختبارات القواعد بدون شاشة
└─ main.gd                # بيختار اللعبة (--game=tug_of_war)
```

## تشغيل على الماك

1. نزّل **Godot 4.5** (النسخة العادية، مش .NET) من godotengine.org.
2. شغّل LiveBridge (شوف `../bridge/README.md`) بالتوكن `test`.
3. افتح Godot ← Import ← اختار `game/project.godot` ← اضغط ▶ (أو F5).
4. النافذة بتطلع صغيرة (450×800) عشان تزبط على الشاشة، بس اللعبة جوّاها 720×1280.
5. بـ LIVE Studio ضيف مصدر **Window Capture** واختار نافذة اللعبة.

**اختيار اللعبة:** `--game=quiz` أو `--game=tug_of_war` (بعد `--`)، أو متغيّر البيئة `LIVE_GAME=quiz`.
وإنت شغّال من المحرر، زر **Tab** بيبدّل بين الألعاب.

بدون بث ولا LiveBridge، بتقدر تجرّب بالكيبورد وإنت شغّال من المحرر:

| زر | الحدث |
|---|---|
| 1 | join (فريق تلقائي) |
| 2 / 3 | تعليق A / B |
| 9 | تعليق عشوائي A أو B أو C أو D (للمسابقة) |
| 4 | 10 لايكات |
| 0 | 50 لايك |
| 5 | فولو |
| 6 | شير |
| 7 | وردة (هدية صغيرة) |
| - | Doughnut (هدية متوسطة) |
| 8 | هدية كبيرة (Corgi 299) |

الاتصال بـ LiveBridge: افتراضياً `ws://127.0.0.1:8765/ws` بالتوكن `test`. لتغييره:
`LIVEBRIDGE_WS=ws://... LIVEBRIDGE_TOKEN=... godot --path game` أو `godot --path game -- --bridge=ws://... --token=...`

## شدّ الحبل: القواعد

- تعليق `A` أو `B` (أو `أ`/`ب`، `1`/`2`) = تنضم أو تنقل لفريق.
- أي تفاعل من حدا بدون فريق بيحطّه بالفريق الأصغر تلقائياً، فكل لايك بيحسب.
- لايك = 0.004، فولو = 0.04، هدية = 0.01 لكل كوين بسقف 0.25، شير = قوة الفريق ×2 لـ 5 ثواني.
  (1.0 = المسافة من النص لخط الفوز، يعني تقريباً 250 لايك بتفوّز من النص.)
- الجولة 3 دقايق أو لحد ما فريق يوصل الخط. بعدها 8 ثواني نتيجة ونجم كل فريق، وجولة جديدة بأسماء فرق جديدة.
- الفرق بتضل محفوظة بين الجولات.
- **لاعبين افتراضيين:** بأول كل جولة بيدخل 5–10 لاعبين بأسماء شخصيات (نينجا، صقر، Turbo...)، مقسومين على الفريقين بالتساوي.
  كل واحد بيشدّ ربع لايك (0.001) كل 2–5 ثواني، فشدّهم بيلغي بعضه. ما بيطلعوا بالتعليقات، وما بيصيروا نجم الجولة،
  وكل مشاهد حقيقي بينضم لفريق بيطلّع منه لاعب افتراضي واحد. لإيقافهم: `godot --path game -- --no-bots`.

كل الأرقام بأول `games/tug_of_war/TugLogic.gd`، وبتتعدّل بعد ما نشوف البث الحقيقي.

## تحدّي المعلومات: القواعد

كل شي أوتوماتيكي، والجولات بتلف لحالها طول البث:

`بين الجولات (15 ث)` ← `10 أسئلة: سؤال (15 ث) ← كشف الجواب (6 ث)` ← `ترتيب البث (12 ث)` ← من جديد

- كل جولة بتختار **1–4 تصنيفات عشوائياً**، وبتاخد 10 أسئلة منها بدون تكرار طول البث (لما يخلصوا بيرجعوا).
- الجواب بتعليق `A` `B` `C` `D` (أو `أ` `ب` `ج` `د`، `1`–`4`). **أول جواب بس بيحسب**.
- النقاط: 100 للجواب الصح + لحد 100 كمان حسب السرعة.
- **الترتيب على مستوى البث بس**: بيبلّش من الصفر مع كل تشغيل للعبة، ومع حدث `stream_end`.

| التفاعل | الأثر |
|---|---|
| كل 50 لايك (من الكل) | حذف جواب غلط للكل (حد أقصى جوابين بالسؤال) |
| فولو | بتقدر تغيّر جوابك مرة |
| شير | نقاطك ×2 بأول جواب صح بعدها |
| هدية صغيرة (1–9 كوين) | +3 ثواني للسؤال ونقاطك ×2 |
| هدية متوسطة (10–99) | حذف جواب غلط للكل ونقاطك ×2 |
| هدية كبيرة (100+) | +10 ثواني ونقاطك ×3 واسمه بشريط فوق |

الوقت الإضافي من الهدايا بسقف 20 ثانية بالسؤال. كل الأرقام بأول `games/quiz/QuizLogic.gd`.

**لاعبين افتراضيين:** كل سؤال بيجاوب فيه 5–10 لاعبين افتراضيين (40% منهم صح) عشان النسب تتحرك.
ما بياخدوا نقاط وما بيطلعوا بالترتيب ولا بالأسرع، وكل مشاهد حقيقي جاوب بالسؤال اللي قبل بياخد محل واحد منهم.

### بنوك الأسئلة (packs)

`games/quiz/packs/general.json`. **الخيار الأول دايماً هو الجواب الصح**، واللعبة بتخلط الخيارات على الشاشة:
```json
{"category": "جغرافيا", "q": "شو عاصمة أستراليا؟", "options": ["كانبرا", "سيدني", "ملبورن", "بيرث"]}
```
⚠️ راجع الأسئلة قبل البث. أي غلطة بالجواب الصح بتبيّن قدام الكل.

**نسخة كرة القدم (لاحقاً):** ملف ثاني `packs/football.json` بنفس الشكل (تصنيفات: أبطال أوروبا، الكلاسيكو، كأس العالم...)،
وبتشغّله بـ `-- --game=quiz --pack=football`. لازم كل تصنيف فيه 10 أسئلة على الأقل.
